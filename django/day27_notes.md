### Django MVT Architecture
- Model - Python classes that define database structure
- View - handles requests, queries database, passes data to template
- Template - HTML files with Django templating language for dynamic pages

### get() vs filter()
- get() - returns single record, raises DoesNotExist if not found,
  raises MultipleObjectsReturned if more than one match
- filter() - returns QuerySet, can return zero or many records,
  returns empty QuerySet if nothing matches, never raises exception
